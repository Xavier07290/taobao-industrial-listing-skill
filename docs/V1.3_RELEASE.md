# V1.3

## V1.3.1 — 竞品视觉基准锁定

当用户选择“高度参考竞品”时启用 REFERENCE LAYOUT LOCK，锁定整体构图、产品占比、背景明暗关系、标题位置和产品视觉重心；禁止将融合式广告擅自改为左右分栏海报。允许替换本商品的产品、文字和品牌，不能推翻选定结构。与参考视觉结构明显不符必须判不合格并重做。

规则同步至主入口、生产流程、视觉规范、提示模板、交付质检及两份分析/设计模板。参考锁定优先于默认风格和占比建议，保留产品真实性和不复制专有素材要求。此项需要实际视觉比对，文件检查脚本不自动判定视觉结构通过。
