## 依赖与代码职责

| 脚本 | 输入 → 输出 | 依赖 |
|---|---|---|
| render_layout.py | JSON与现成图片/字体 → 单张PNG | Pillow Image/ImageDraw/ImageFont；标准库 |
| compose_detail_long.py | 8张有序详情屏 → 长图 | Pillow Image；标准库 |
| make_contact_sheet.py | 已有独立成品 → 缩略预览 | Pillow Image/ImageDraw；标准库 |
| verify_and_package.py | 15张PNG及可选文档 → manifest与ZIP | Pillow Image/ImageChops；hashlib、zipfile等标准库 |

requirements.txt 的 `Pillow>=10.0.0` 覆盖当前4个脚本的第三方导入；没有脚本依赖缺失。测试只增加标准库 unittest，无新第三方依赖。实际验证环境为 Windows、Python3.12.14、Pillow12.3.0；没有完成Python3.10/Pillow10.0及Linux/macOS版本矩阵。最低版本声明与未来Pillow版本兼容性仍需CI验证。

脚本不实现AI背景生成、产品抠图或事实提取；这些明确属于Agent外部能力。现有样例引用的图片与字体不随仓库提供，直接原样运行样例会缺文件，需按运行文档配置。

## Bug 与修复记录

| 编号 | 问题和原因 | 修复 |
|---|---|---|
| B01 | 仅文件SHA判重，PNG重编码后重复内容漏检 | 增加尺寸与解码RGBA像素哈希，保留原文件SHA |
| B02 | 失败重跑不清理旧正式ZIP，可能误交付旧结果 | 在检查前保留带stale后缀的旧包；新包临时写入并校验后生效 |

## 尚存工程边界与V1.3建议

1. 优先统一目录契约：文档推荐final/与根目录说明文件，但现有打包器只读取一个目录且说明文件可选。当前运行文档给出交付副本的兼容方式；V1.3建议显式project-root/image-dir和必需文档校验。
2. 增加布局JSON Schema与图层角色：产品层强制contain、禁止非等比变形、检查放大比例、画布边界及字体字形覆盖。当前通用合成器仍允许cover/stretch，也不自动判断低清放大或品牌真实性，调用Agent必须遵守Skill。
3. 将视觉与事实审核记录结构化，并绑定最终文件哈希，防止审核后改图或将机器通过冒充整套通过。纯白背景、主体完整、中文语义、技术参数和危险场景仍不能由当前尺寸脚本判定。
4. 增加Python/Pillow与Windows/Linux/macOS CI矩阵；明确依赖支持范围，提供可复现锁定环境。增加失败磁盘写入、并发运行和极长图内存测试。目前未测并发；不应让两个进程同时写同一交付目录。
5. 增加跨Agent能力探测和安装版本检查，统一ChatGPT、Codex及其他客户端调用契约。先用同一已批准基准图验证外部背景/抠图工具，再逐张生产，不以并行生成速度换质量。
6. 补充可授权的实物回归素材与独立版式基准；本轮几何夹具仅承担文件工程回归，不可扩展成商品设计模板或对外商品样例。

完整命令、字体与路径要求、真实商品流程和降级边界见 [LOCAL_RUN.md](LOCAL_RUN.md)。审计阶段未升级版本号或推送main；随后按用户授权整理为V1.3发布。
