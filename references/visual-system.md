# V1.2 黑红工业电商视觉系统

## 设计目标

在保留用户认可的黑红工业广告质感基础上，高参考度学习同类竞品的版式组织。重点是构图、信息层级、产品占比、卖点卡片、视觉节奏和阅读路径，不是只复制几句卖点，也不是套用一张通用PPT模板。

## 竞品版式参考规则

每张竞品图先拆解为模块，再映射到当前商品：
- 头部品牌/型号区；
- 核心标题区；
- 产品主体区；
- 卖点卡片/图标区；
- 参数/规格区；
- 场景/服务/下单须知区；
- 底部CTA或说明区。

记录各模块的相对位置、宽高、间距、对齐方式、视觉权重和阅读顺序。建议用0–1000归一化坐标，方便在不同分辨率画布上复现版式比例。

保留一般布局关系、模块数量和信息层级；必须替换对方品牌、Logo、完整文案、产品照片、专有图标和受保护图稿。当前商品参数与卖点必须重新核验。

## 统一视觉令牌

| 角色 | 建议颜色 |
|---|---|
| 工业红 | #C90E1C / #E42226 |
| 近黑 | #15171A |
| 炭灰 | #2A2E33 |
| 金属银 | #B9BEC4 |
| 白色 | #FFFFFF |
| 警示黄 | #E9B22D（少量使用） |

色彩不是硬性限制。若用户提供的参考图具有明确且不同的品牌色，优先按用户确认的风格参考。

## 产品主体

- 产品主体优先占画面约35%–65%，以完整、清晰和构图平衡为先；
- 保留原始比例，不能横向或纵向拉伸；
- 真实产品层置于背景之上、文字之下或与文字层按蓝图安排；
- 铭牌、吊钩、链条、外壳、螺丝和接口必须保持清晰；
- 产品边缘有明显抠图瑕疵时回退处理，不用模糊/发光遮盖；
- 细节图必须裁自真实照片，不生成虚构内部结构。

## 五张主图的视觉任务

### 01 核心成交图
大标题 + 真实产品主体 + 一个核心事实卖点 + 2–3个辅助标签。优先复现参考竞品的标题/产品相对位置和视觉重心。不要堆砌十几个参数。

### 02 规格选择图
借鉴竞品的规格矩阵、型号卡片或分栏布局。只呈现当前商品真实可售规格，表格由排版工具绘制，避免小字拥挤。

### 03 产品细节图
借鉴竞品的多特写分区结构。每个特写都必须来自真实产品照片，并用短标题说明可见结构；不能用生成齿轮、制动器、内部剖面冒充实拍。

### 04 应用场景图
借鉴竞品的场景分格或大场景构图。场景应与产品实际用途相符，真实产品主体必须作为独立图层合成，避免不安全操作。

### 05 下单须知图
借鉴竞品的信息卡片/步骤说明布局。用图标、序号和简短文字解决选型、发货、运费、开票和售后问题；只写已确认规则。

## 详情页视觉任务

1. Hero：产品大图与核心价值；
2. 规格：清晰矩阵或选项卡；
3. 细节：真实局部放大；
4. 参数：表格与单位；
5. 场景：产品与环境；
6. 供货/物流：时间与费用边界；
7. 下单须知：确认事项；
8. CTA：客服选型信息。

每屏沿用统一字体、颜色、边距、卡片圆角和标签样式，但不能让八屏都变成相同布局。

## 字体与可读性

- 标题使用清晰粗体中文字体，避免过度压缩或倾斜；
- 正文和参数使用高可读字体；
- 小屏预览仍能看清关键标题和数字；
- 文字不要贴边，保证安全边距；
- 文字、数字、单位和表格通过准确排版工具叠加；
- 没有合适中文字体时停止渲染，不使用方框乱码。

## 背景与光效

可以使用深灰金属、真实厂房、仓库、钢板纹理、局部轮廓光、红色强调条和低强度粒子。背景必须服务产品，不能压过产品或干扰文字。背景生成时不得生成产品、Logo、文字或参数。

## 质量检查

检查：产品占比、产品清晰度、与参考版式的相似关系、标题层级、卖点密度、文字可读性、留白、颜色对比和五张图的差异化。若看起来像简陋PPT卡片，退回重新设计；若看起来像竞品复制件，替换专有素材与表达。
