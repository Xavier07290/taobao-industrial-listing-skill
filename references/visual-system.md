# 黑红工业电商视觉系统

## 核心风格

专业B端工业品、高对比中文大标题、真实重工质感、炭灰金属背景、红色强调、清晰规格参数、机械产品占主视觉。用户认可的HS-T图只作配色与信息结构灵感，**不能把该示例图的产品本体或未经证实宣传当成真实资料**。

## 标准配色

| 角色 | 颜色 |
|---|---|
| 工业红 | `#C90E1C` / `#E42226` |
| 近黑 | `#15171A` |
| 炭灰 | `#2A2E33` |
| 金属银 | `#B9BEC4` |
| 白色 | `#FFFFFF` |
| 少量警示黄 | `#E9B22D` |

## 视觉层级

1. 品牌与真实型号。
2. 高可读大标题，优先单一利益点。
3. 产品主体（推荐占画面35%–65%，以保证完整为先）。
4. 2–3个可证实卖点标签。
5. 辅助参数/物流/注意事项。

## 布局

- 1440×1920 的3:4主图，独立输出五张，不要一张五联拼贴。
- 图片清晰、手机端文字足够大，避免过密。
- 背景可以是虚化工厂、仓库、钢板纹理和少量工业线条。
- 真品照片保留铭牌、钩链、连接点的清晰可辨。
- 参数页面用清楚的数字网格，过多规格优先展示代表信息及指向SKU。
- 局部放大必须从真实原图裁切。

## 图像模型注意

生成式模型可能扭曲汉字、铭牌或产品部件。最稳妥的技术流程是：AI生成无字背景 → 使用原图抠图保真合成 → 使用图像编辑器或程序添加准确的中文、表格和标识 → 核对。这也是要求“产品样式绝不变”的重要保障。

## 详情图

每屏建议宽1440px、高1200至2200px；可分段上传淘宝编辑器，避免一张过长造成文字模糊。长图拼接时保留原始多屏文件。

## V1.1：用户认可的精致拼版视觉 ≠ 最终单文件

必须保存并复制该风格特征：粗体大字、红黑白工业色块、真实机械产品的大幅特写、工厂空间光影、深灰金属质地、富有层级的规格表和服务模块。**不要因为改成逐张导出，就降低为黑底白框+普通表格的简陋模板。** 单张图的视觉质量应能放大作为原拼版里任意一格的完整版。

设计可以先用总览做方向确认，但最终用户获得的是各自独立1440×1920的 `main_01.png`–`main_05.png`，而不是一张大图。详情页分8屏导出，保持专业视觉并无损拼接。文件验收见 `references/delivery-contract.md`。
