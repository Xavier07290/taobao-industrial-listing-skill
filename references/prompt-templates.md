# V1.2 图像生成、版式分析与合成提示模板

这些提示模板用于 Agent 调用当前可用的图像生成/编辑工具。提示词本身不能保证机械产品绝对保真；必须用真实产品图层合成，并通过视觉检查。

用户选择“高度参考竞品”时，所有提示与后期合成都必须携带 design_master.md 中的 REFERENCE LAYOUT LOCK：参考图编号、整体构图、产品占比、背景明暗分区、标题位置和产品视觉重心。锁定项优先于下面的默认黑红配色及通用分栏示例；不可将融合式产品广告改成左右分栏信息海报。只替换本商品真实产品、原创文字、品牌和专有素材，不能随意推翻已选版式。输出与参考结构明显不符时必须判 FAIL 并重做，不得只因文字或尺寸正确就接受。

## 1. 竞品版式解析

请逐张分析竞品图片，不要先生成图片。记录：
- 画布比例、边距、分区数量和阅读路径；
- 标题、副标题、产品主体、卖点、参数表和CTA的位置；
- 产品主体在画面中的相对占比、方向和视觉重心；
- 卡片、标签、图标、特写和场景图的组织方式；
- 字体粗细、颜色比例、背景质感、光线和视觉节奏；
- 竞品每张图试图解决的买家疑问。

使用0–1000归一化坐标记录模块位置。输出竞品版式蓝图，并将每个竞品卖点映射为 VERIFIED、VISIBLE、GENERIC 或 UNVERIFIED。保留一般版式逻辑，但不得复制竞品品牌、Logo、完整文案、专有插画或产品主体。

## 2. 生成无字背景

只生成用于商品广告的背景/场景，不要生成任何产品、机械零件、吊钩、链条、Logo、品牌标志、中文、英文、数字、参数表、图标或水印。画面要预留产品图层和文字版面空间，遵循指定的参考版式比例、留白、光线方向和颜色节奏。背景必须具有高质量工业广告质感，不要做成普通PPT底板。

## 3. 产品抠图与锁定

以用户提供的真实产品照片作为唯一产品来源。制作透明背景产品层时保留全部真实像素、颜色、比例、铭牌、Logo、螺丝、吊钩、链条、接口和配件。不得重绘、补全、删除或美化产品结构。边缘不确定时保留原图背景，不要猜测轮廓。输出透明PNG并与原图对照检查。

## 4. 产品合成

把透明真实产品层放入已批准的背景。只允许等比例缩放和位置调整，不允许透视变形、拉伸、液化、局部重绘或重新生成产品。保留原始铭牌和结构。产品应处于参考版式中相应的视觉位置和占比。先完成产品与背景合成，再添加文字。

## 5. 精确文字与图表

不要让图像模型生成中文、Logo、型号、数字、参数、单位、表格或二维码。使用真实字体和排版工具渲染准确文字。每个文本元素都从 design_master.md 读取，逐字核对。表格数据必须与 product_facts.md 一致。文字溢出时调整布局或字号，不要裁掉文字。

## 6. 主图设计提示

### main_01 核心成交
只制作一张独立3:4画布。高参考度复现竞品的主标题/产品主体/卖点分区关系，替换为当前商品真实产品、品牌、原创文案和已核实卖点。产品主体清晰、完整、比例真实。背景高质感黑红工业广告风。不要生成多图拼版。

### main_02 规格选择
只制作一张独立3:4画布。按竞品规格矩阵或分栏布局组织当前商品的真实SKU，数字、单位和型号由排版工具叠加。禁止补充未提供的规格。

### main_03 产品细节
只制作一张独立3:4画布。用真实照片裁切展示2–4个外观细节，参考竞品的多卡片/特写布局。没有实拍的内部结构不得出现。

### main_04 应用场景
只制作一张独立3:4画布。生成合理的工业场景背景，随后合成真实产品图层。遵循竞品场景图的分格或主场景布局，禁止不安全吊装动作。

### main_05 下单须知
只制作一张独立3:4画布。参考竞品步骤卡片/信息模块，展示已确认的规格核对、发货、物流、开票、批量采购和售后信息。

## 7. 详情页分屏

逐屏独立制作：01 Hero、02规格、03真实结构、04参数、05场景、06供货物流、07下单须知、08客服CTA。每屏宽1440px，使用统一视觉系统但布局不同。表格与正文后期精确排版，八屏完成后再拼接长图。

## 8. 每次生成的强制约束

- 一次只生成一张独立完整画布；
- 不允许五联图、九宫格或多屏拼贴作为成品；
- 产品必须来自真实产品图层；
- 不生成文字、数字、Logo或参数；
- 版式参考用户指定的竞品图，不可退化成普通信息卡；
- 每张图生成后立即检查，再进入下一张；
- 不合格时修正该张，不要带着错误继续生成整套。
