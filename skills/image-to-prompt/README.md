# 图片反推提示词 Skill

上传参考图，反推构图、主体、动静关系、材质光影、文案与图标，输出可直接用于出图的完整中文提示词。支持对比参考图与生成图并修正。无需API Key；使用当前对话的读图能力，受该环境能力与额度限制。

## 本地使用

将本目录保存为个人技能目录下的 image-to-prompt 文件夹，确保入口为 image-to-prompt/SKILL.md。Windows 默认位置为 C:\Users\你的用户名\.codex\skills\image-to-prompt\SKILL.md。

在支持该Skill的对话中附图并输入：
“使用 $image-to-prompt，分析这张图片并给出完整绘图提示词。”

只要求提示词时不会自行出图。若要出图，明确说“按提示词生成图片”，并使用支持图片生成的环境。

## 从 GitHub 使用

本目录包含完整Skill；不要把仓库根目录的另一个SKILL.md误装成本技能。

可以把本目录链接交给有仓库读取能力的助手，要求读取SKILL.md并按其执行。如果对话不能读取链接，打开“直接粘贴版.txt”，复制全文到对话，再上传图片。GitHub负责存放与分发，本身不执行读图或出图。

[技能入口](SKILL.md) · [直接粘贴版](直接粘贴版.txt)

## 工作方式

- 新图片：实际读图，输出本图具体描述，不套用齿轮或淘宝五图模板。
- 结果有偏差：对比构图、比例、动静、光效和文字，输出局部修正。
- 修正满意：将修正融入完整Prompt，消除互相矛盾的指令。
- 未识别内容如实说明；图片广告声明不自动成为商品事实。

此目录不包含商品原图、API密钥或项目数据。
